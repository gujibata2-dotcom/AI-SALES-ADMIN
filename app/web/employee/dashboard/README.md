# Performance and review

Metrics: task_success_rate, accuracy, customer_satisfaction, response_quality, human_correction_rate, escalation_rate, policy_violation_rate, average_resolution_time.

Composite review considers Quality + Accuracy + Safety + Customer Experience + Business Outcome + Reliability. Safety and Ethics are hard constraints; sales conversion cannot offset a violation.

Review flow: Collect Outcomes → Evaluate → Compare Baseline → Human Review → Improvement Recommendation.

Phase 12 Learning recommendations enter Phase 19 Evaluation → Governance → Approval → Version → Release. New knowledge, prompts, skills, workflows, or policies never become production behavior directly.
