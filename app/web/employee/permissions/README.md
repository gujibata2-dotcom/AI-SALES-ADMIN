# Permissions

Categories: `READ`, `WRITE`, `CREATE`, `UPDATE`, `DELETE`, `SEND`, `PUBLISH`, `SCHEDULE`, `APPROVE`, `ESCALATE`.

Critical permissions—financial, legal, security, privacy, production deployment—remain policy-gated and require human approval where required.

Permissions are explicit, least-privilege, auditable, and independent of skills. No permission is inherited merely from role title, department, team hierarchy, or delegation.

Any request to grant, revoke, or alter permissions must pass Governance and authorization controls. An AI Employee cannot grant permission to itself or create unrestricted agents.
