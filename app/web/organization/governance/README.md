# Governance integration

All employee lifecycle, role, permission, delegation, assignment, release, and retirement actions are subordinate to: BUSINESS OWNER → GOVERNANCE → POLICY → AUTHORIZATION → AUDIT.

Phase 19 is the release gate for changes to prompts, policies, knowledge, skills, workflows, agent configuration, or behavior. Approval and versioning are mandatory where policy requires them.

AI cannot approve important work of itself, alter governance, disable safety, tamper with audit, or bypass Action Gateway.
