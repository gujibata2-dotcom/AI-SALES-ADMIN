# Task assignment

Customer/request → Task Created → Find suitable employee → Check skills → Check permission → Assign → Execute → Verify.

Assignment considers skill, domain, risk, authorization, availability, workload, and manager/governance rules.

Workload states track active, queued, blocked tasks and capacity. Overload results in reassign, queue, or escalation.

Every action records employee_id, task_id, action, authorization, policy, timestamp, and result.
