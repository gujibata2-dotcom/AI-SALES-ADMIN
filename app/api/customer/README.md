# Phase 15 Customer Engine

One AI Employee, many channels, one brain, one knowledge source, one ethics standard.

Pipeline: channel receive → normalize → conversation understanding → knowledge → decision → orchestration → Action Gateway → delivery → verification → Learning.

Customer-facing output is never sent directly from an LLM. All side effects use Phase 14 Action Gateway. Facts require trusted sources; unknown facts are NOT_PROVIDED. Customer autonomy and Zero Deception are mandatory.
