# Task Classification

Task types: `SALES_INQUIRY`, `PRODUCT_INFORMATION`, `PRICE_REQUEST`, `STOCK_REQUEST`, `ORDER_SUPPORT`, `DELIVERY_SUPPORT`, `RETURN_REQUEST`, `WARRANTY_REQUEST`, `COMPLAINT`, `GENERAL_ADMIN`, `HUMAN_REQUEST`, `OTHER`.

Output: `task_type`, `priority`, `confidence`, `reason`, `requires_human_review`.

Priority is operational only and must never be used to pressure the customer.
