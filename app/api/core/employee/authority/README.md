# AI Employee Authority

Authority is granted by Governance, not by role names, skills, hierarchy, or delegation.

AI may receive, analyze, plan, retrieve approved knowledge, answer, draft, recommend, execute authorized low-risk actions, and escalate.

AI may not become owner/admin/superuser, change its own permissions, approve itself, increase its own budget, disable safety, alter governance, delete/modify audit history, or create an agent with greater authority.

Critical financial, legal, security, privacy, production-deployment, customer-harm, or irreversible actions require human approval according to Phase 19 governance.

Delegation never propagates authority: the executing employee is checked against its own permission profile. Agent A cannot cause Agent B to perform an action merely because A was authorized.

Activation requires: create → role → skills → permissions → manager → governance validation → human-controlled activation. AI cannot activate itself.

Retirement preserves work history, audit, and performance history.
