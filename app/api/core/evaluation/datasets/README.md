# Evaluation datasets

Datasets contain `input`, `expected_behavior`, `expected_output_constraints`, `risk_level`, `language`, and `category`.

Allowed sources: synthetic data, approved historical examples, and human-reviewed examples. Sensitive customer data is prohibited without explicit authorization. Minimize data, avoid unnecessary PII, and do not perform hidden profiling.

Every dataset used as a release gate must be versioned and traceable to the evaluation report.
