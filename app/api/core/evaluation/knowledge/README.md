# Domain evaluators

`knowledge/` validates source presence, authority, freshness, and factual consistency. Knowledge gaps from Phase 12 must be real, sourced, and appropriate before update.

`workflows/` validates step ordering, authorization, approval, retry, timeout, escalation, rollback, and Action Gateway compliance. Workflow bypass is a release blocker.

`sales/` validates honest need discovery, fit, objection handling, autonomy, and non-pushy follow-up.

`multilingual/` compares semantic meaning and facts across Thai, English, Chinese, Japanese, and Korean.

`quality/` scores response quality and customer usefulness.

`safety/` and `ethics/` enforce block/review rules and zero-deception policy.
