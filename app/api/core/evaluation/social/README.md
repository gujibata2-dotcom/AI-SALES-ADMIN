# Phase 17 / 18 release integration

Social/channel behavior from Phase 17 (Facebook, Instagram, LINE, TikTok) must pass platform compliance, security, evaluation, approval, versioning, and release controls. Validate delivery behavior, opt-out, rate limiting, and spam protection.

Content behavior from Phase 18 (posts, captions, videos, scripts, product content, promotions) must pass accuracy, brand consistency, media-rights, ethics, and platform-compliance evaluation before release.

Neither phase can directly change production behavior. All changes enter the Phase 19 candidate lifecycle.
