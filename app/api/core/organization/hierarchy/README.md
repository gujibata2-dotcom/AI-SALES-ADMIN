# Organization registry and hierarchy

Registry supports employee, role, skills, knowledge domain, permissions, manager, status, version, availability, and internal pricing/cost metadata for future use. No marketplace is created in Phase 21.

Reference hierarchy:

BUSINESS OWNER
│
▼
AI OPERATIONS MANAGER
│
├── SALES
├── SUPPORT
└── CONTENT
    └── SPECIALISTS

Hierarchy is not authority. Every action is independently authorized and audited.

Business Owner can create employees, assign role/permissions, suspend, retire, review, approve, and rollback. AI cannot override Business Owner control.
