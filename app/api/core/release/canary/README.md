# Canary control

States: CANARY → PROMOTE / PAUSE / ROLLBACK.

Use small controlled traffic, monitor against the production baseline, and compare quality, safety, accuracy, customer experience, and business outcomes.

Metrics: error rate, response quality, customer complaints, human corrections, hallucination rate, safety violations, conversion, support resolution, and latency.

Critical safety failure, major accuracy regression, high complaint spike, security issue, or policy violation requires rollback. AI cannot disable canary or rollback protection.
