# Decision Intelligence Contracts

Signals are classified as FACT, SIGNAL, INFERENCE, or ASSUMPTION. Every metric records source, timestamp, period, and confidence. Recommendations expose WHY, EVIDENCE, RISK, ALTERNATIVES, and UNKNOWN without exposing hidden chain-of-thought.

Critical financial, legal, security, privacy, employment, irreversible, or high-risk customer-impact decisions require human approval. The engine may analyze and recommend, but cannot self-approve, self-escalate privileges, change policy, disable governance, delete audit evidence, or execute external actions directly.

Decision lifecycle:
COLLECT -> UNDERSTAND -> CORRELATE -> ANALYZE -> RISK/OPPORTUNITY -> OPTIONS -> SIMULATE -> RECOMMEND -> HUMAN DECISION -> EXECUTE -> VERIFY -> LEARN.
