# Decision & Orchestration Engine — Phase 13

Decision and orchestration coordinate existing understanding, knowledge, context, learning insights, policy checks, authorization, workflows, actions, and verification.

**UNDERSTAND → DECIDE → VALIDATE → ORCHESTRATE → EXECUTE → VERIFY → LEARN**

Core invariants:
- DECISION ≠ AUTHORIZATION
- Decision Engine is not Policy Engine.
- Learning is accepted only after approval.
- No guessing, fabrication, deception, policy bypass, or autonomous financial action.
- Hidden chain-of-thought is never exposed; only structured rationale summaries are retained.
