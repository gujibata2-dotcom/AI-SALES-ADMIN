# Retrieval Gaps

Always distinguish:

1. `KNOWLEDGE_EXISTS_BUT_NOT_FOUND` — authoritative knowledge exists, but retrieval did not surface it.
2. `KNOWLEDGE_DOES_NOT_EXIST` — authoritative sources do not contain the required information.

A retrieval failure must never be treated as proof that knowledge does not exist. Retrieval recommendations may adjust query normalization, synonyms, multilingual retrieval, ranking, or source weighting only within existing source-authority rules.
