# Learning & Continuous Improvement Engine — Phase 12

The Learning Engine observes operational outcomes and proposes improvements. It never authorizes itself.

**OBSERVE → ANALYZE → IDENTIFY GAP → PROPOSE IMPROVEMENT → HUMAN REVIEW → VALIDATE → APPROVE → PUBLISH → MONITOR**

Core invariant: **LEARN, BUT NEVER SELF-AUTHORIZE.**

Learning is subordinate to ethics, safety, privacy, business authority, and human approval. It may recommend changes; it may not alter policy authority, source-of-truth authority, or deploy changes autonomously.
