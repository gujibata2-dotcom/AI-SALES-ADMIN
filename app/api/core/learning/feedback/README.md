# Human Feedback

Supported labels:
- CORRECT
- INCORRECT
- PARTIALLY_CORRECT
- MISSING_INFORMATION
- WRONG_PRODUCT
- WRONG_LANGUAGE
- WRONG_TONE
- UNSUPPORTED_CLAIM
- POLICY_VIOLATION

Every correction must include a source/reference. A human correction is not automatically authoritative knowledge; it requires verification against the appropriate source of truth. Feedback may be malicious, poisoned, injected, or mistaken and must be evaluated accordingly.
