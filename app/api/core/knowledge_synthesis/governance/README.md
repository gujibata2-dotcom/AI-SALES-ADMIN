# Knowledge Governance

Major knowledge updates require evidence, validation, review, versioning and publication. Human review is mandatory for high-impact/high-risk/sensitive/major-policy knowledge or uncertain evidence. AI peer review is independent of the creator.

Access classes: PUBLIC, INTERNAL, RESTRICTED, CONFIDENTIAL. Distribution is eligibility-based and relevance-first; knowledge is not broadcast to every employee. Every use and outcome can be traced through knowledge_id, source, evidence, versions, review, approval, usage and outcome.
