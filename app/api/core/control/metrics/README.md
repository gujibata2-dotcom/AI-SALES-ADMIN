# Metrics

Operational metrics: task_completion_rate, response_latency, knowledge_hit_rate, knowledge_verification_rate, human_escalation_rate, action_success_rate, action_failure_rate, approval_wait_time, customer_clarification_rate.

Sales signals: qualified_conversations, recommendations, purchase_ready_signals.

Never optimize sales volume by sacrificing honesty, autonomy, safety or accuracy. Metrics require traceable source data.
