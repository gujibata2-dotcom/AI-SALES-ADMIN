# Default workforce teams

### Sales
Sales Generalist + Product Specialist + Customer Support Specialist. Flow: customer → need analysis → specialist → verified recommendation → sales response.

### Support
Support Agent + Product/Technical Specialist + Human Support; escalate by risk.

### Content
Content Planner → Copywriter → Visual/Video Specialist → Compliance Reviewer → Publisher. Publish requires approval.

### Research
Research Agent → Source Verification → Domain Specialist → Human Reviewer. Source before confidence.

### Operations
Task Manager + Workflow Agent + Admin Agent + Monitoring Agent.

Manager names are organizational abstractions; authority comes only from Governance.
