# Consensus and conflict resolution

Consensus is evidence-based, not majority-vote based. Compare evidence, source quality, confidence, and conflicts.

When agents disagree on a fact such as price: detect conflict → check authoritative sources → check Knowledge Engine/version → prefer verified source → human review if unresolved.

Low confidence means DO NOT GUESS: clarify, retrieve more knowledge, escalate, or request human review. Senior/specialist labels never override Governance.
