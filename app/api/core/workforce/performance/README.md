# Team performance and learning

Metrics: team_success_rate, task_completion, accuracy, customer_satisfaction, human_correction, escalation_rate, latency, failure_rate, policy_violations. Keep individual and team performance separate; never optimize conversion at the expense of safety or ethics.

Outcomes: Team Success, Team Failure, Human Correction, Customer Feedback, Conflict, Escalation → Phase 12 Learning.

Learning proposals for knowledge gaps/conflicts/updates cannot publish directly. Flow remains Learning → Phase 19 Evaluation → Governance → Approval → Release; knowledge changes also follow Phase 3 Knowledge Governance.
