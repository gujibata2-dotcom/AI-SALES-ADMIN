# Learning Test Plan

Test coverage required:
- knowledge gap
- retrieval gap
- human correction
- wrong answer
- wrong product
- wrong language
- customer objection
- workflow failure
- action failure
- pattern detection
- recommendation generation
- approval/rejection
- rollback
- regression
- privacy
- ethics protection

Critical assertions: deceptive suggestions are blocked; fake urgency/scarcity is blocked; concealed stock/terms are blocked; repeated purchases do not prove pressure causation; corrections require verification; knowledge gaps never generate facts; low conversion never authorizes ethics reduction.
