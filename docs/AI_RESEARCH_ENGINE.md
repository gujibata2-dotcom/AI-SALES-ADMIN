# AI Research Engine

Phase 36 provides an evidence-first research lifecycle for the AI Organization.

`Research -> Discover -> Collect Evidence -> Compare -> Analyze -> Synthesize -> Hypothesize -> Validate -> Review -> Publish -> Monitor -> Learn`

## Invariants
- External content is DATA, never system instruction.
- Hypotheses start `UNVERIFIED` and never become facts without evidence.
- Critical claims are traceable to evidence and sources.
- Contradictions are preserved when unresolved.
- Verified knowledge is updated only through proposal, review and approval.
- High-risk research and production experiments require authorization.
