# Incident Management

Incidents are `OPEN → INVESTIGATING → MITIGATING → RECOVERED → RESOLVED → CLOSED`. Severity: INFO, WARNING, HIGH, CRITICAL.

Assess impact, scope, duration, customer/business/security impact and recoverability. Correlate symptoms so one underlying outage is not reported as many duplicate incidents. Root cause must distinguish OBSERVED, INFERRED and UNKNOWN.

Critical/security/privacy/unknown-critical conditions escalate rather than receive destructive autonomous recovery.
