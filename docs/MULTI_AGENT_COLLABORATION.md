# Multi-Agent Collaboration

Modes: sequential, parallel, conditional, bounded loop, event-driven. Dependencies must be satisfied before execution. Each handoff carries context, objective, completed work, evidence, open questions, risks and next action.

Delegation is scoped, permission-checked, risk-bounded and auditable. No unrestricted delegation or recursive agent chains. Shared context is partitioned into PUBLIC, TEAM, EMPLOYEE and SENSITIVE scopes.
