# Phase 46 — AI Workforce

Phase 46 adds a tenant-bound coordination layer for multiple AI Employees. An Employee remains a role/capability/knowledge/permission contract; a model is only an execution resource.

Flow: Goal → Decompose → Match capabilities → Assign → Dependencies/parallelism → Collaborate/Handoff → Review → Authorize → Execute through Phase 44 runtime → Verify → Synthesize → Outcome/Learning.

The module is provider-neutral and standard-library only. It does not claim model, tool, billing, or social connectivity that is not configured. Cross-tenant access is rejected through the existing Phase 44 TenantStore.
