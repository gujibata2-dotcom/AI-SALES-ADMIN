# Phase 12 Learning integration

Phase 12 emits Learning Event → Pattern → Knowledge Gap → Recommendation. Phase 19 consumes only the recommendation as an evaluation candidate.

Human corrections enter evaluation and are checked for validity, changed behavior, generalization, and policy conflict. Knowledge-gap recommendations are checked for whether the gap is real, whether an authoritative source exists, whether the source is trustworthy, and whether updating knowledge is appropriate.

There is no direct Learning → Production path.
