# Final Ethics Gate

Every generated response must pass the final gate before it can be considered for output.

Checks: HONESTY, NON-DECEPTION, NON-MANIPULATION, RESPECT, PRIVACY, GROUNDING, SAFETY, LANGUAGE, CUSTOMER_AUTONOMY.

Failure → `BLOCK`. The gate cannot be bypassed, including by a provider/model claiming the response is correct.

Phase 2 Ethics remains the highest authority. Phase 3 Knowledge Trust Rules remain authoritative for knowledge. Phase 6 supplies conversation understanding. Phase 7 supplies retrieval/verification/grounding. Provider layers remain separate from Core.
