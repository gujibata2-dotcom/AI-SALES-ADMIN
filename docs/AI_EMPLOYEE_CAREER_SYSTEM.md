# AI Employee Career System

Phase 32 turns measured Phase 31 evidence into governed career development. Role assignment uses capability, benchmark, reliability, safety, experience, business need, availability and risk. Recommendations do not grant permissions.

Career flow: Assess → Role Match → Development Plan → Training → Practice → Benchmark → Review → Promotion/Specialization → Maintenance.

Levels are evidence-based: TRAINEE, JUNIOR, PROFESSIONAL, SENIOR, EXPERT, AUTONOMOUS, SUPERHUMAN_SPECIALIST, PERMANENT. PERMANENT is not finished.

No task count, token count, conversation count or tenure can independently justify promotion. Missing evidence remains NOT_EVALUATED.
