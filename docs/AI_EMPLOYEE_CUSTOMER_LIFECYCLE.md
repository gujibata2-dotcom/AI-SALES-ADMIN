# AI Employee Customer Lifecycle

1. Create organization
2. Start trial
3. Browse and configure a supported Employee Catalog item
4. Hire under a package entitlement
5. Execute work through the Phase 44 runtime
6. Meter usage and enforce quota
7. Observe outcomes/dashboard
8. Upgrade, downgrade or cancel with authorization
9. Retain data according to policy

Cross-tenant access is rejected by the reused Phase 44 `TenantStore` organization checks. Customer-facing value uses observed usage/outcomes; the service does not manufacture sales, leads, ROI or performance figures.
