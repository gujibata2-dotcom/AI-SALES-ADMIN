# Employee Registry

Registry records mission, responsibility, capabilities, limitations, tools, permissions and success metrics. Roles are extensible without changing core architecture. Initial roles include Executive/Coordinator, Sales, Customer Support, Admin, Product Specialist, Marketing, Content Creator, Operations, QA, Security, Software Engineer, Researcher and Data Analyst.

Status: TRAINING, ACTIVE, PAUSED, SUSPENDED, REVIEW, RETIRED. Capability claims require registry evidence. Least privilege is mandatory.
