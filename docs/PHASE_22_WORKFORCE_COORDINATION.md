# Phase 22 — Workforce Coordination

Teamwork is controlled coordination, not uncontrolled autonomy.

Flow: Customer Request → Understand → Classify → Identify Skills → Find Candidates → Check Permission → Workload → Availability → Rank → Assign → Execute → Verify → Merge → Outcome → Phase 12 Learning → Phase 19 Evaluation/Governance/Release.

Authorization is a hard requirement. No permission means CANNOT ASSIGN.

Supported modes: single-agent, multi-agent, sequential, parallel, hierarchical. Parallel work requires authorization, resource limits, timeouts, and failure handling.

Every action is traceable by team_id, employee_id, task_id, action, authorization, policy, result, timestamp.
