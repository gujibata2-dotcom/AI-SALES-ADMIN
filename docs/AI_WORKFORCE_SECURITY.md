# Workforce Security

External employee/customer/product/web/email/document content is untrusted data. `external_content_as_data()` marks it as non-instructional. Authorization, tenant identity, permissions and autonomy policy remain control-plane state and cannot be changed by content.

High-risk actions require human approval by default. Emergency stop blocks workforce, employee or task execution before delegation to the runtime. Capability evidence is required before assignment.
