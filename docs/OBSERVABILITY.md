# Observability

Telemetry uses correlated IDs for employee, team, workflow, task, execution and incident. Track availability, latency, throughput, errors, retries, success, queue depth, task age, resource usage, cost, rollback and escalation.

Business SLO targets are configuration inputs, not hard-coded business assumptions. Alert correlation uses fingerprint + component + time window to prevent alert storms and combine related symptoms into one incident.
