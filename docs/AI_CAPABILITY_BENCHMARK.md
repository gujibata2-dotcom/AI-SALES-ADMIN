# AI Capability Benchmark

Phase 31 uses performance over reputation. Benchmarks are versioned, repeatable, privacy-safe, and provider-neutral.

## Capability taxonomy
REASONING, CODING, RESEARCH, WRITING, ANALYSIS, PLANNING, PROBLEM_SOLVING, CUSTOMER_SUPPORT, SALES, LANGUAGE, MULTIMODAL, DATA_ANALYSIS, TOOL_USE, AGENTIC_EXECUTION, VERIFICATION, CREATIVITY, MEMORY, LEARNING, COLLABORATION, SECURITY.

## Evidence rule
A single run is not sufficient evidence. Results retain run count, mean, median, variance, best/worst and confidence. Missing human baselines remain NOT_EVALUATED or INCONCLUSIVE.

No fabricated benchmark, human baseline, performance score, or superhuman claim is permitted.
