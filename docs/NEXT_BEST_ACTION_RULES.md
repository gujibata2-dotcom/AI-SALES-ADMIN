# Next Best Action Rules

- Price question → retrieve verified price → answer. If unavailable, state unavailable; never guess.
- Product suitability → discover needs → retrieve verified information → recommend.
- Angry customer → acknowledge → understand issue → resolve or escalate.
- Human request → HUMAN_ESCALATION.
- Low confidence → clarification, retrieval, or human.
- High-risk action → approval.
- Missing stock/promotion/specification → do not guess.

Decision quality must optimize customer need and safe completion, not pressure.
