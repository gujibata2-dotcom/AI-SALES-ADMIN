# Cognitive Architecture

Phase 29 models bounded AI cognition as software subsystems: attention, working memory, episodic/semantic/procedural memory, reasoning, experience, reflection, learning and adaptation. It does not claim consciousness, emotions or subjective experience.

Flow: Observe → Focus → Remember → Understand → Reason → Act → Observe Outcome → Learn → Reflect → Research → Verify → Evaluate → Improve.

Relevance precedes memory volume; working memory is bounded and expirable.
